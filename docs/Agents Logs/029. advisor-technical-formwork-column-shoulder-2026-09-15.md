## Algorithm (Revit geometry)

**Trigger:** `entry.Role == Column && entry.ClipHeightApplied && rule.KeepUnjoinedAround` contains `"Beam"`.

**Inputs:** clipped `SolidEntry` column (`ClipBottomZM`, `ClipTopZM`, `BoundingBox`), document beams (reuse horizontal gather pattern from `HeightClipResolver.GatherHorizontals` or beam entries from `SolidProvider`).

**Per beam candidate:**

1. Footprint overlap with column XY bbox (+ `probeEpsilonMm` pad) — reuse `HeightClipResolver.FootprintsOverlap`.
2. Z overlap: beam bottom/top intersect `[clipBottom, clipTop]`.
3. **Framing face:** beam `LocationCurve` direction vs column local axes (from `BoundingBox` or `Transform`):
   - If beam runs along column X → abuts ±Y faces → face width = column Y extent.
   - If beam runs along column Y → abuts ±X faces → face width = column X extent.
   - Require beam center offset toward that face (not passing through column core only).
4. **Width compare:** `beamWidthM` = bbox dimension perpendicular to beam axis; `faceWidthM` = column face width on abutting face.
5. If `beamWidthM + ε < faceWidthM`:
   - `stripWidthM = (faceWidthM - beamWidthM) / 2`
   - `overlapHeightM = min(beamTop, clipTop) - max(beamBottom, clipBottom)`
   - `shoulderM2 += 2 * stripWidthM * overlapHeightM` (both shoulders on that face pair).

**Optional v2 (if bbox falsifies):** extrude two vertical quads and `SolidProvider.TryBoolean` intersect with column side shell — not in attempt 1 unless falsifier hits.

**Out of scope:** slab shoulders; beam wider than column; unjoined beams with no footprint overlap; Wall `keepUnjoinedAround`.
