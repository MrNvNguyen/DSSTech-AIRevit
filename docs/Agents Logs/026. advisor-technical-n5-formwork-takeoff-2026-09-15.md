## API design

### 1. Command — `FormworkTakeoffCommand`

```csharp
namespace QSNormEngine.Revit;

[Transaction(TransactionMode.Manual)]
public sealed class FormworkTakeoffCommand : IExternalCommand
{
    public Result Execute(ExternalCommandData commandData, ref string message, ElementSet elements);
}
```

**Execute flow (no write Transaction until Ghi):**

1. `uidoc = commandData.Application.ActiveUIDocument` — fail if null.
2. `FormworkScopeDialog.Show()` → `FormworkScopeMode` (`Selection` | `ActiveView` | `WholeModel`).
3. `var filter = FormworkScopeResolver.Resolve(doc, uidoc, mode)` — empty → cancel dialog.
4. WholeModel: if `filter.Count > 500` (constant), `TaskDialog` warn + user confirm continue.
5. Load rules:
   ```csharp
   var rulesPath = PluginPaths.FormworkRules;
   var ruleSet = FormworkRuleSetLoader.Load(rulesPath);
   var rulesSha = FormworkRuleSetLoader.Sha256Hex(rulesPath);
   ```
6. `var batch = FormworkCalculator.Compute(doc, ruleSet, filter, rulesPath, rulesSha);`
7. `var rows = FormworkTakeoffRowAggregator.FromBatch(batch);` — one display/write row per `ElementId` (segments summed).
8. Modal:
   ```csharp
   var window = new FormworkResultsWindow(rows, doc, batch);
   new WindowInteropHelper(window).Owner = commandData.Application.MainWindowHandle;
   window.ShowDialog();
   ```
9. Return `Result.Succeeded` (analysis-only; writes happen inside window on Ghi).

### 2. Scope — `FormworkScopeResolver`

```csharp
internal enum FormworkScopeMode { Selection, ActiveView, WholeModel }

internal static class FormworkScopeResolver
{
    public static IReadOnlyList<ElementId> Resolve(
        Document doc,
        UIDocument uidoc,
        FormworkScopeMode mode);

    /// <summary>Categories supported by Config/formwork-rules.json (Column/Beam/Slab).</summary>
    public static bool IsFormworkCandidate(Element e);
}
```

| Mode | Source |
|---|---|
| `Selection` (default) | `uidoc.Selection.GetElementIds()` filtered to formwork categories |
| `ActiveView` | `FilteredElementCollector(doc, doc.ActiveView.Id)` + category filter |
| `WholeModel` | `FilteredElementCollector(doc)` + category filter |

Use same category set as rules: `OST_StructuralColumns`, `OST_StructuralFraming`, `OST_Floors` (skip `skip:true` types via calculator).

### 3. Core DTO — `FormworkTakeoffRow` + aggregator

```csharp
namespace QSNormEngine.Core.Formwork;

public sealed class FormworkTakeoffRow
{
    public required string ElementId { get; init; }
    public string Kind { get; init; } = "";
    public FormworkElementRole Role { get; init; }
    public int SegmentCount { get; init; }
    public double SideAreaM2 { get; init; }
    public double BottomAreaM2 { get; init; }
    public double DeductAreaM2 { get; init; }
    public double WaitPourAreaM2 { get; init; }  // always 0.0 this wave (pipeline inert)
    public double TotalAreaM2 { get; init; }
    public bool GroundContactDropBottom { get; init; }
    public string Confidence { get; init; } = "High";  // "High" | "Low"
    public string Warnings { get; init; } = "";
    public string Status { get; init; } = "OK";
}

public static class FormworkTakeoffRowAggregator
{
    public static IReadOnlyList<FormworkTakeoffRow> FromBatch(FormworkBatchResult batch);
}
```

**Aggregation policy (write + grid):** group `batch.Elements` by `ElementId`; sum Side/Bottom/Deduct/Total; `WaitPourAreaM2 = 0`; `GroundContactDropBottom = any segment true`; `Confidence = Low` if any segment `Status != "OK"` or `UNSUPPORTED`; `Warnings` = distinct `Reason`/status messages joined `|`.

**Transaction:** `"DSS.QSEngine formwork write"` — started only inside `WriteResults`.

**Per row (eligible: `Status == "OK"` or write all with Low flagged in message — prefer write all computed rows, skip `UNSUPPORTED`):**

| Param | Value |
|---|---|

| `QS_FormworkConfidence` | `Confidence` |
| `QS_FormworkStamp` | `DateTime.UtcNow.ToString("O")` |

**Implementation notes:**

- Call `SharedParameterSetup.EnsureBound(doc, PluginPaths.Root/Config/QS_SharedParameters.txt)` inside tx (same as `NormWriteBack`).
- Reuse `QsParameterFiller.SetParam` logic for NUMBER/YESNO/TEXT — extract shared `QsParamWriter.TrySet(element, name, value)` **only if** lead hits duplication; otherwise copy minimal `TrySetParam` block into `FormworkWriteBack` (surgical).
- **Forbidden parameter names:** `QS_NormCode`, `QS_NormStatus`, `QS_NormStamp`, `QS_WorkItemId` — no references in this class.
- On bind failure: message directs user to **Setup Parameters** (fold N4 bind).
